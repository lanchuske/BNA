🏠 Información General

Esta aplicación permite gestionar y visualizar la estructura organizacional del BNA (Banco de la Nación Argentina) de manera interactiva.

🎯 Características Principales:

  • Visualización Jerárquica: Árbol interactivo de unidades organizativas
  • Edición en Tiempo Real: Modificar datos sin recargar la página
  • Validación Automática: Detección de inconsistencias en los datos
  • Historial de Cambios: Seguimiento de todas las modificaciones
  • Exportación de Datos: Generar archivos CSV actualizados

📊 Estructura de Datos:

  • Unidad Organizativa: Nombre de la unidad
  • Jerarquía: Nivel en la estructura organizacional
  • Reporta a: Unidad superior directa
  • Misión: Propósito y responsabilidades
  • Funciones Genéricas: Actividades generales de la unidad
  • Funciones Específicas: Tareas concretas con porcentaje de dedicación

📁 Gestión de Archivos

📥 Cargar Archivo CSV:

  1. Haz clic en "Examinar..." para seleccionar un archivo CSV
  2. O ingresa manualmente la ruta del archivo en el campo de texto
  3. Haz clic en "Cargar Archivo"
  4. El sistema validará automáticamente la integridad de los datos

📋 Formato del Archivo CSV:

El archivo debe contener las siguientes columnas:

  • Unidad Organizativa - Nombre de la unidad
  • Jerarquía - Nivel jerárquico (1, 2, 3, etc.)
  • Reporta a - Unidad superior (vacío para unidades raíz)
  • Misión - Descripción de la misión
  • Tipo de Función - "Genérica" o "Específica"
  • Descripción - Descripción de la función
  • Producto Final - Resultado esperado
  • Porcentaje Dedicación - Solo para funciones específicas

💾 Estado de Datos:

El panel muestra información sobre:

  • Última Importación: Archivo y fecha de carga
  • Última Exportación: Archivo y fecha de exportación
  • Estado Actual: Sincronización con el archivo original

✏️ Modo Edición

🚀 Activar Modo Edición:

  1. Haz clic en "Entrar en modo edición"
  2. Los botones de edición aparecerán junto a cada unidad
  3. Haz clic en una unidad para editarla

📝 Editar Información de Unidad:

  • Nombre: Cambiar el nombre de la unidad
  • Reporta a: Seleccionar la unidad superior
  • Jerarquía: Ajustar el nivel jerárquico
  • Misión: Modificar la descripción de la misión

➕ Agregar Nueva Unidad:

  1. En modo edición, haz clic en el botón "+" junto a la unidad padre
  2. Se creará una nueva unidad con datos por defecto
  3. Edita los campos según sea necesario

🗑️ Eliminar Unidad:

  1. Haz clic en el botón "×" junto a la unidad
  2. Confirma la eliminación
  3. ⚠️ Precaución: Se eliminarán también todas las unidades hijas

🎨 Características del Modo Edición:

  • Fuente Courier New: Todos los campos de texto usan fuente monoespaciada
  • Tamaños Unificados: Consistencia visual en todos los campos
  • Guardado Automático: Los cambios se guardan automáticamente
  • Indicador de Guardado: Notificación visual cuando se guardan los cambios

⚙️ Gestión de Funciones

📋 Tipos de Funciones:

  • Funciones Genéricas: Actividades generales de la unidad
  • Funciones Específicas: Tareas concretas con porcentaje de dedicación

➕ Agregar Función:

  1. Selecciona una unidad en modo edición
  2. Haz clic en "+ Agregar" en la sección de funciones
  3. Completa los campos requeridos

📋 Copiar Funciones de Otra Unidad:

  1. Haz clic en "📋 Copiar de Unidad"
  2. Selecciona la unidad origen del menú desplegable
  3. Marca las funciones que deseas copiar
  4. Haz clic en "Copiar Selección"

🗑️ Eliminar Función:

  1. Haz clic en el botón "✕" junto a la función
  2. La función se eliminará inmediatamente

📊 Porcentajes de Dedicación:

  • Solo aplica a funciones específicas
  • El sistema valida que la suma no exceda el 100%
  • Se muestran advertencias si los porcentajes no suman 100%

🔄 Reordenar Funciones:

  1. Usa el ícono "⋮⋮" para arrastrar y soltar
  2. Las funciones se reordenarán automáticamente

🔍 Validación de Datos

🚨 Tipos de Problemas Detectados:

  • Estructura Básica: Campos obligatorios faltantes
  • Jerarquía: Inconsistencias en la estructura organizacional
  • Duplicados: Unidades con nombres idénticos
  • Contenido: Campos vacíos o con formato incorrecto
  • Porcentajes: Suma incorrecta de dedicación

🔧 Resolución de Problemas:

  • Corrección Automática: Algunos problemas se resuelven automáticamente
  • Selección Manual: Elegir entre opciones disponibles
  • Entrada de Texto: Escribir valores personalizados
  • Selección Múltiple: Elegir de una lista de opciones
  • Información Contextual: Datos adicionales para tomar decisiones

📋 Validación Manual:

  1. Haz clic en "🔍 Validación de Integridad"
  2. El sistema ejecutará todas las validaciones
  3. Revisa los resultados en el modal
  4. Exporta el reporte si es necesario

💡 Información Contextual:

Para problemas complejos, el sistema proporciona:

  • Funciones Relacionadas: Otras funciones similares en la organización
  • Estadísticas: Distribución de tipos de función
  • Jerarquía: Información sobre la estructura organizacional
  • Recomendaciones: Sugerencias basadas en patrones existentes

📋 Historial y Cambios

📋 Ver Últimos Cambios:

  1. Haz clic en "📋 Últimos Cambios"
  2. Se abrirá un modal con la lista cronológica de cambios
  3. Los cambios se muestran con fecha y hora

🔄 Deshacer Cambios:

  1. Haz clic en "↶ Deshacer" (se activa cuando hay cambios)
  2. Se deshará el último cambio realizado
  3. El botón se desactiva cuando no hay más cambios para deshacer

📊 Tipos de Cambios Registrados:

  • Agregar Unidad: Creación de nuevas unidades organizativas
  • Eliminar Unidad: Eliminación de unidades
  • Agregar Función: Creación de funciones genéricas o específicas
  • Eliminar Función: Eliminación de funciones
  • Copiar Funciones: Copia de funciones entre unidades
  • Reordenar Funciones: Cambio en el orden de las funciones

💾 Persistencia de Datos:

  • Los cambios se guardan automáticamente en el navegador
  • El historial se mantiene entre sesiones
  • Los datos persisten hasta que se exporten o se cargue un nuevo archivo

📤 Exportación

📄 Exportar a CSV:

  1. Haz clic en "Exportar CSV"
  2. Se descargará automáticamente un archivo CSV
  3. El nombre incluye la fecha y hora de exportación

📄 Exportar a PDF:

  1. Haz clic en "📄 Exportar PDF"
  2. Se generará automáticamente un archivo PDF
  3. Cada unidad organizativa ocupará una página separada
  4. Incluye misión, funciones genéricas y específicas
  5. Formato profesional con tablas estructuradas

📋 Contenido del Archivo Exportado:

  • Todas las unidades organizativas
  • Todas las funciones (genéricas y específicas)
  • Información de jerarquía y reportes
  • Misiones y descripciones actualizadas
  • Porcentajes de dedicación para funciones específicas

📊 Reportes de Validación:

  • Se pueden exportar reportes de validación
  • Incluyen todos los problemas detectados
  • Formato de texto para fácil lectura

💡 Consejos y Trucos

⚡ Mejores Prácticas:

  • Validar Regularmente: Ejecuta validaciones antes de exportar
  • Revisar Porcentajes: Asegúrate de que sumen 100% en cada unidad
  • Usar Nombres Únicos: Evita duplicados en nombres de unidades
  • Guardar Cambios: Los cambios se guardan automáticamente

🔧 Solución de Problemas:

  • Archivo No Carga: Verifica que sea un archivo CSV válido
  • Cambios No Se Guardan: Revisa la conexión a internet
  • Validación Falla: Revisa el formato de los datos
  • Navegador Lento: Cierra otras pestañas para liberar memoria

🎯 Funciones Avanzadas:

  • Copiar Múltiples Funciones: Usa la función de copia para ahorrar tiempo
  • Reordenar Jerarquía: Cambia el campo "Reporta a" para reorganizar
  • Validación Contextual: Usa la información adicional para tomar decisiones
  • Historial Detallado: Revisa el historial para entender cambios previos

📱 Compatibilidad:

  • Navegadores: Chrome, Firefox, Safari, Edge
  • Dispositivos: Escritorio, tablet, móvil
  • Archivos: CSV con codificación UTF-8
